# Compiler Socket Support

## Overview

Added Socket class support to the dosjava compiler (djc.exe) to enable compilation of Java programs using Socket functionality.

## Changes Made

### 1. Compiler Semantic Analyzer (tools/compiler/semantic.c)

#### Added Socket to Built-in Classes
**Location**: Line 83-92 (builtin_classes array)

Added `"Socket"` to the list of built-in classes that the compiler recognizes.

```c
const char* builtin_classes[] = {
    "BufferedWriter",
    "BufferedReader",
    "FileOutputStream",
    "FileInputStream",
    "OutputStream",
    "InputStream",
    "Date",
    "Socket",  // Added
    NULL
};
```

#### Registered Socket Methods
**Location**: Line 346-467 (register_builtin_classes function)

Added registration for 6 Socket static methods:

1. **Socket.init()** - void
   - Initializes mTCP subsystem
   - No parameters
   - Static method

2. **Socket.new(String host, int port)** - Socket
   - Creates and connects a socket
   - Parameters: host (String), port (int)
   - Returns: Socket object
   - Static method

3. **Socket.close(Socket sock)** - void
   - Closes a socket
   - Parameters: sock (Socket)
   - Static method

4. **Socket.send(Socket sock, String data)** - int
   - Sends data through socket
   - Parameters: sock (Socket), data (String)
   - Returns: bytes sent (int)
   - Static method

5. **Socket.recv(Socket sock, int bufsize)** - String
   - Receives data from socket
   - Parameters: sock (Socket), bufsize (int)
   - Returns: received data (String)
   - Static method

6. **Socket.isConnected(Socket sock)** - int
   - Checks socket connection status
   - Parameters: sock (Socket)
   - Returns: 1 if connected, 0 otherwise (int as boolean)
   - Static method

## Usage Example

```java
class SocketTest {
    public static void main() {
        Socket.init();
        Socket sock = Socket.new("127.0.0.1", 80);
        if (Socket.isConnected(sock)) {
            int sent = Socket.send(sock, "GET / HTTP/1.0\r\n\r\n");
            String response = Socket.recv(sock, 256);
            System.out.println(response);
        }
        Socket.close(sock);
        return;
    }
}
```

## Technical Notes

### Method Signature Design

All Socket methods are **static** because:
- Current compiler doesn't support instance methods
- Simplifies implementation
- Matches System.out.println() pattern
- Socket object passed as first parameter (except init())

### Type System

- Socket class is registered as TYPE_CLASS
- Methods return appropriate types:
  - void for init(), close()
  - Socket (TYPE_CLASS) for new()
  - int (TYPE_INT) for send(), isConnected()
  - String (TYPE_CLASS) for recv()

### Symbol Table

Socket methods are added to the global symbol table during semantic analysis phase, making them available for identifier resolution and type checking.

## Compatibility

- **Backward compatible**: Existing programs without Socket usage compile unchanged
- **No breaking changes**: Only additions to built-in class list
- **Memory impact**: Minimal (6 method symbols + 1 class symbol)
